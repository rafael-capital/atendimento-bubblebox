Política de Privacidade — Bubble Box Avaliacoes

Última atualização: 21 de outubro de 2026

Quem somos

O "Bubble Box Avaliacoes" é uma ferramenta interna da Bubble Box Sorocaba, rede de 3 lavanderias de autoatendimento em Sorocaba-SP (Centro, Jardim Simus e Vila Olímpia). Responsável: Rafael Sales. Contato: sorocababbox568@gmail.com.

Para que serve

A ferramenta acessa apenas os Perfis da Empresa no Google das nossas 3 lojas, para avisar o dono quando chega uma avaliação nova de cliente e preparar uma sugestão de resposta. A resposta só é publicada depois de aprovada pelo dono. A ferramenta não acessa perfis de outras empresas nem dados de outros usuários do Google.

Quais dados usamos

As informações das avaliações das nossas lojas que já são públicas no Google: nome de quem avaliou (como aparece no Google), nota, comentário e data. Também usamos a identificação da nossa própria conta e das nossas lojas no Google.

Como usamos

  • O texto da avaliação é enviado a um serviço de inteligência artificial (OpenAI) apenas para escrever a sugestão de resposta.
  • O aviso, com a sugestão de resposta, é enviado ao WhatsApp do dono da Bubble Box.
  • Guardamos apenas o código de cada avaliação já avisada, para não avisar a mesma avaliação duas vezes.

O que não fazemos

Não vendemos, não alugamos e não compartilhamos esses dados com ninguém além do necessário para o funcionamento descrito acima. Não usamos os dados para publicidade nem para criar perfis de pessoas.

Uso limitado (Google)

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como remover o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Pedidos sobre dados: sorocababbox568@gmail.com.
